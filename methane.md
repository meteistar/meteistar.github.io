## Project Overview
NeutrinoViewer is a **Qt/QML application** designed for **real-time video and sensor data visualization**.  
It integrates gas sensors and other telemetry streams, providing operators with live feedback.  
Supports KLV metadata overlay, low-latency video streaming, and interactive controls for analyzing environmental data.

**Tech Stack:**  
- 💻 C++, QML, Qt Widgets  
- 🎥 FFmpeg, GStreamer  
- 🧪 SQLite, Custom Data Streams (KLV)  
- 🛠️ QMake, CMake, Vcpkg, Conan
